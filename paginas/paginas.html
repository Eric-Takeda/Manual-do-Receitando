Organização das telas

O Receitando é dividido em diferentes telas, cada uma responsável por uma parte da experiência do usuário. Essa organização facilita a navegação e a manutenção do código.

As telas são desenvolvidas com Flutter e utilizam widgets para construir elementos como botões, campos de texto, imagens, listas e barras de navegação.

1. Tela de cadastro

A tela de cadastro permite criar uma nova conta para utilizar o aplicativo.

As informações preenchidas são encaminhadas ao Supabase Auth. Os dados complementares do perfil podem ser armazenados na tabela profiles, conforme a implementação do cadastro.

--------------------------------------------------------------------------------------------------------------------------------------------------------------------------

Principais elementos:

  • Nome de usuário;
  • Campo para e-mail;
  • Campo para senha;

2. Tela de login

A tela de login permite que um usuário já cadastrado entre em sua conta utilizando e-mail e senha.

Os dados informados são enviados ao serviço de autenticação do Supabase. Quando a autenticação é bem-sucedida, o usuário pode acessar o menu principal.

--------------------------------------------------------------------------------------------------------------------------------------------------------------------------

Principais elementos:

  • Campo para e-mail;
  • Campo para senha;
  • Botão para entrar;
  • Acesso ao cadastro;
  • Opção de recuperação de senha.

3. Tela de recuperação de senha

Essa tela permite solicitar a recuperação de acesso por meio de um e-mail. O processo depende das configurações de autenticação e dos redirecionamentos definidos no Supabase.

Após receber o link de recuperação, o usuário pode ser encaminhado ao fluxo de definição de uma nova senha, conforme a configuração do aplicativo.

--------------------------------------------------------------------------------------------------------------------------------------------------------------------------

Principais elementos:

  • Endereço de e-mail para o envio da solicitação de nova senha;

4. Menu principal

O menu principal é a tela apresentada após o acesso à conta. Ele serve como ponto de partida para navegar pelas principais áreas do sistema.

Entre os acessos disponíveis na implementação estão a consulta de receitas e o cadastro de uma nova receita. Outras opções podem ser acessadas por suas respectivas telas quando estiverem integradas ao menu.

--------------------------------------------------------------------------------------------------------------------------------------------------------------------------

Principais elementos:

  • Receitas;
  • Criação de Receitas;
  • Lista de Favoritos;
  • Perfil do Usuário;
  • Configurações do Aplicativo;
  • Sair da conta;

5. Tela de receitas

A tela de receitas apresenta os pratos cadastrados no banco de dados. Ela permite pesquisar receitas, filtrar por categoria e selecionar uma receita para consultar mais informações.

--------------------------------------------------------------------------------------------------------------------------------------------------------------------------

Elementos principais:

  • Campo de pesquisa;
  • Seleção de categorias;
  • Cartões com informações das receitas;
  • Imagens das preparações, quando disponíveis;
  • Navegação para a tela de detalhes.

6. Tela de detalhes da receita

Essa tela exibe as informações completas da receita selecionada, incluindo título, descrição, ingredientes, modo de preparo, tempo e quantidade de porções, conforme os dados cadastrados.

A tela também contém a ação de favoritar. A opção de editar deve estar disponível somente para receitas que o usuário tenha permissão para modificar.

--------------------------------------------------------------------------------------------------------------------------------------------------------------------------

Principais elementos:

  • Visualização das informações e imagens cadastradas;
  • Opção de favoritar quaisquer receitas;
  • Opção de editar receitas cadastradas que foram criadas pelos usuários.

7. Tela de cadastro de receita

A tela de cadastro permite inserir uma nova receita. Ela reúne os campos necessários para registrar as informações da preparação e seus ingredientes.

Também permite selecionar uma imagem da galeria do dispositivo. Os dados são armazenados no Supabase, e a imagem é enviada ao armazenamento configurado para as fotos das receitas.

--------------------------------------------------------------------------------------------------------------------------------------------------------------------------

Principais elementos:

  • Adicionar informações das receitas;
  • Adicionar imagens das receitas.

8. Tela de edição de receita

Essa tela permite atualizar os dados de uma receita criada pelo próprio usuário, respeitando as regras de acesso do sistema.

É possível alterar os campos disponíveis e substituir ou remover a imagem, conforme as opções implementadas. As receitas previamente disponibilizadas pelo sistema não devem ser alteradas ou excluídas pelo usuário comum.

--------------------------------------------------------------------------------------------------------------------------------------------------------------------------

Principais elementos:

  • Adicionar informações das receitas;
  • Adicionar imagens das receitas.

9. Tela de favoritos

A tela de favoritos reúne as receitas que o usuário marcou para consultar posteriormente.

Os favoritos são relacionados à conta autenticada e recuperados do banco de dados. Ao selecionar um item, o usuário pode acessar os detalhes da receita.

--------------------------------------------------------------------------------------------------------------------------------------------------------------------------

Principais elementos:

  • Opção de visualizar as receitas favoritadas.

10. Tela de perfil

A tela de perfil apresenta informações da conta do usuário e permite atualizar os dados disponibilizados nessa área.

Entre os recursos previstos estão a visualização dos dados pessoais cadastrados e a seleção de uma foto de perfil. A imagem é armazenada no Supabase Storage e associada ao perfil.

--------------------------------------------------------------------------------------------------------------------------------------------------------------------------

Principais elementos:

  • Visualizar seu nome, email e data de criação da conta;
  • Opção de adicionar foto de perfil e visualiza-las;
  • Edição de nome da conta e foto de perfil.

11. Configurações

A tela de configuração apresenta mais informações internas sobre o aplicativo.

Entre os recursos previstos estão as opções de mudar de tema, alteração de senha, perfil e mais informações sobre o aplicativo;

--------------------------------------------------------------------------------------------------------------------------------------------------------------------------

Principais elementos:

  • Navegação para mudar de senha, tema, conta, perfis e informações do Receitando.

12. Alterar senha

A tela de alteração de senha permite o usuário logado trocar a senha desejada.

Basta apenas digitar um senha nova e confirmar a senha nova.

--------------------------------------------------------------------------------------------------------------------------------------------------------------------------

Principais elementos:

  • Alteração de senha.

13. Tema

A tela de tema permite que o usuário troca a cor do sistema.

Entre os temas estão os "Claro", "Escuro" e "Sistema". Por padrão do aplicativo, é inicializado com o "Sistema".

--------------------------------------------------------------------------------------------------------------------------------------------------------------------------

Principais elementos:

  • Alteração tema claro - Cor predominante Branca;
  • Alteração tema escuro - Cor predominante Escura arroxeado;
  • Alteração tema sistema - Cor predominante amarelada, igual este manual técnico;

13. Sobre o aplicativo

Permite visualizar informações sobre o aplicativo.

--------------------------------------------------------------------------------------------------------------------------------------------------------------------------

Principais elementos:

  • Visualização do nome do criador;
  • Visualização da logotipo do Receitando;
  • Visualização da versão do aplicativo;
  • Visualização de uma pequena descrição;

Navegação entre as telas

A navegação conecta as telas conforme as ações realizadas pelo usuário. O fluxo geral de utilização pode ser representado da seguinte forma:

  1. O usuário abre o aplicativo.
  2. Realiza o login ou cria uma conta.
  3. Acessa o menu principal.
  4. Entra na tela de receitas ou inicia o cadastro de uma nova receita.
  5. Seleciona uma receita para consultar os detalhes.
  6. Quando permitido, edita suas próprias receitas ou utiliza a funcionalidade de favoritos.
  7. Acessa o perfil para consultar ou atualizar suas informações.

Considerações finais

A divisão do aplicativo em telas independentes contribui para a organização do projeto. Cada tela possui uma responsabilidade específica e se comunica com as demais por meio da navegação implementada no Flutter.
